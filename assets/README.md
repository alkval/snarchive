# Artwork

`icon.png` is Snarchive's raster launcher image and Android adaptive foreground source. It uses an opaque navy
background with padding for Android's outer mask; `app.json` configures the matching adaptive background colour.

The folded-paper character and archive box are Snarchive artwork. They are not the Snapchat logo. Keep source
artwork in this directory so isolated builds can include the assets referenced by the application configuration.
